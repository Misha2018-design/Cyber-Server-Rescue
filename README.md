# Cyber-Server-Rescue
Суть та сюжет: Ви з друзями — команда елітних програмістів (або хакерів у хорошому сенсі), чию школу чи офіс атакував небезпечний вірус. Ваша мета — проникнути всередину віртуальної мережі комп'ютерів, зібрати фрагменти вкраденого коду та знешкодити головного боса-віруса до того, як він знищить усі дані.

## Запуск гри

Відкрийте `index.html` у сучасному браузері. Керуйте гравцем клавішами ← / → або A / D та уникайте вірусів. Якщо вірус торкнеться гравця, натисніть Enter або кнопку «Грати знову», щоб почати заново.
